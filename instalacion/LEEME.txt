HDZ STUDIO - INSTALACION Y ACTUALIZACIONES

INSTALADOR EXE (recomendado)
La aplicacion se instala en %LOCALAPPDATA%\Programs\HDZ Studio.
No se reutiliza la ruta protegida de una instalacion antigua en Program Files.
Se conservan ajustes, credenciales e historial del perfil de Windows actual.
La instalacion antigua no se elimina ni se alteran videos o torrents.

La aplicacion no necesita ejecutarse como administrador. Si falta PowerShell 7,
se solicita permiso de Windows solo para instalar ese prerrequisito desde el
MSI incluido. Las herramientas audiovisuales vienen en el paquete y se
comprueba su SHA256; no se descargan versiones "latest" durante la instalacion.

El menu contextual de capturas es opcional. Marcarlo puede pedir permisos para
registrar la integracion de Windows. Sin el, las capturas siguen disponibles
dentro de HDZ. Se puede instalar despues con Instalar-menu-capturas.ps1.

PAQUETE PORTABLE
Descomprime la distribucion completa en una carpeta donde tu usuario pueda
escribir. Entra en instalacion y ejecuta "Instalar HDZ Studio.cmd".
No eleves toda la instalacion: PowerShell 7, si falta, pide sus propios
permisos. El menu contextual se instala por separado. Al acabar abre el
acceso directo del Escritorio o del Menu Inicio.

ACTUALIZAR DESDE EL PC
El boton aparece junto a la version cuando hay una publicacion nueva. Con el
menu plegado esta encima del boton del menu. Solo descarga archivos distintos,
comprueba firma y SHA256, conserva respaldo y reabre el programa.

Si la instalacion antigua esta en Program Files y no puede escribir, el boton
solicita UAC. Al cancelar, HDZ permanece abierto. Al aceptar se eleva solamente
el actualizador: un ayudante sin elevar reabre HDZ con el usuario original.

ACTUALIZAR DESDE LA WEB
La instalacion por usuario permite completar la actualizacion sin intervenir
en el PC. Una instalacion protegida que necesite UAC muestra una explicacion
en la web; no abre un aviso invisible de Windows.

VERSIONES ANTIGUAS QUE YA BLOQUEAN EL BOTON
El boton antiguo no puede corregirse antes de actualizar. Cierra HDZ y ejecuta
"Actualizar HDZ Studio.cmd" desde instalacion, aceptando UAC, o usa el nuevo
EXE para pasar a una instalacion por usuario. No hace falta borrar claves.
La copia antigua queda intacta; los nuevos accesos apuntan a la carpeta del
usuario. No es necesario desinstalar la copia antigua para hacer este cambio.

DESINSTALAR
El EXE incluye su desinstalador de Windows. Los ajustes del perfil se conservan.
No se eliminan accesos o integracion que apunten a otra instalacion de HDZ.

PUBLICACION
El EXE se compila solo desde el paquete de Preparar-Release.ps1, no desde el
workspace sin filtrar. Ver PUBLICAR.txt y LICENCIAS.txt.
